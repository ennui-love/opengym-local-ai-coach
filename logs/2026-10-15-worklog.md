## 桌面 `openGym-server` 文件夹不可删除

用户问：「桌面上的 openGym-server 文件夹还有存在的必要吗？」

**结论：不能删。它并非单纯部署包，而是运行中的 Docker 容器的 live 数据目录。**

`docker-compose.yml` 含 `./data:/data` 绑定挂载，容器内 `/data` 直接映射到该文件夹。实测 `data/` 内容：

| 文件 | 内容 |
|---|---|
| `db.json` | 数据库（用户、passkey、设备链接） |
| `state-<uid>.json` | 该用户的训练方案 |
| `coach.json` | AI Coach 全局配置与调用日志 |
| `coach/<uid>.json` | 该用户的教练任务记录 |
| `secret` | passkey 签名密钥 |
| `vapid.json` | Web Push 密钥（publicKey / privateKey） |
| `audit.log` | 审计日志 |

**删除 = 丢账号 + 丢计划 + 教练配置失效 + passkey 失效，容器重启变全新实例。**

另外，桌面 `backups/data-localhost-<timestamp>.tar.gz` 是切 Tailscale 域名前的 localhost 旧备份，**origin 不对，不能用于恢复现账号**。

---

## 想搬家怎么办

安全，前提是整体搬：

```bash
docker compose down
# 剪切整个文件夹到新位置
cd <新位置>/openGym-server
docker compose up -d
```

因为用的是相对路径绑定 + 固定 `name: opengym`，数据不丢。**仅当彻底弃用时**才在备份后删除。
